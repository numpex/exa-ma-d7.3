\paragraph{Additional Details:}

\begin{description}
\item[\textbf{Documentation}]
\emph{Each CGAL package includes a user manual that explains the algorithm's procedure, along with implementation details and performance metrics.}

\begin{itemize}
  \item \textbf{Topics Covered:} Algorithm procedures, implementation details, and performance metrics
  \item \textbf{Format:} Web pages
  \item \textbf{Timeline:} Continuous updates with new releases and improvements
\end{itemize}

\item[\textbf{Tutorials}]
\emph{Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
  \item \textbf{Modules Included:} Introductory tutorials, example programs, and video sessions
  \item \textbf{Target Audience:} Graduate students and domain scientists
  \item \textbf{Existing Materials:} \url{https://doc.cgal.org/latest/Manual/tutorials.html}, \url{https://www.youtube.com/watch?v=UdhjJPG_ic8}, \url{https://www.youtube.com/watch?v=cYEfNPfBufk}
\end{itemize}

\end{description}

\subsubsection{Next Steps for CGAL}
\label{sec:CGAL:next-steps}

To enhance CGAL training, we've identified key areas to focus on. Some efforts are already in progress, and the following sections outline our strategic goals and additional steps to improve our training programs.

\begin{itemize}
    \item \textbf{New Training Content:}
    \begin{itemize}
        \item \textbf{Documentation Updates:} Continuously update user manuals and reference guides for each CGAL package used in NumPEx, i.e. \href{https://doc.cgal.org/latest/Mesh_3/index.html}{3D Mesh Generation} and    \href{https://doc.cgal.org/latest/Alpha_wrap_3/index.html}{3D Alpha Wrapping}
        \item \textbf{Advanced Tutorials:} Develop advanced tutorials for specific use cases and applications.
    \end{itemize}

    \item \textbf{Incorporating Exascale Techniques and User Feedback:}
    \begin{itemize}
        \item \textbf{User Feedback Loop:} Establish a structured feedback loop to incorporate user experiences and suggestions into future updates.
    \end{itemize}

\end{itemize}
