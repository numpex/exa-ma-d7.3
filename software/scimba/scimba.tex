\paragraph{Additional Details:}

\begin{description}

    \item[\textbf{Documentation}]
          \emph{Short Description: Documentation generated by sphinx from the python code.}

          \begin{itemize}
              \item \textbf{Content:} Covers installation, basic usage, several test cases
              \item \textbf{Format:} Available as webpages and PDF, generated by sphinx
              \item \textbf{Development:} An ongoing open-source effort using sphinx, welcoming community contributions
          \end{itemize}

    \item[\textbf{Tutorials}]
          \emph{Short Description: Examples in the scimba repository.}

          \begin{itemize}
              \item \textbf{Content:} Covers most of the content available in scimba
              \item \textbf{Target Audience:} Users of scimba
              \item \textbf{Format:} Available python files
              \item \textbf{Development:} An ongoing open-source effort, welcoming community contributions by writing example python files
          \end{itemize}

\end{description}


\subsubsection{Next Steps for Scimba}
\label{sec:Scimba:next-steps}

To enhance the training initiatives for Scimba, we have identified several key areas of focus. Some of these steps are already in progress or have initial contributions. The following sections outline our strategic goals and the additional steps we plan to take to further improve our training programs:
\begin{itemize}
    \item \textbf{New Training Content:}
          We are in the process of rewriting scimba, with the help of an engineer hired by Inria (Rémi Imbach). This will lead to a new version of scimba, with a new API and new features. We will update the documentation and tutorials to reflect these changes.
    \item \textbf{Incorporating Exascale Techniques and User Feedback:}
          Using the issue system of gitlab, we will collect feedback from users and update the documentation and tutorials accordingly.
          Community contributions are thus welcome, as the reach of scimba is steadily growing in the community.
          We will also incorporate the latest exascale techniques (e.g., multi-GPU parallelization, which is planned for 2025) into the training materials.
    \item \textbf{Expanding Delivery Formats:}
          We already have regular meetings with interested users to discuss new and upcoming features. We will continue to hold these meetings and expand them to include more users.
          moreover, they will include interactive sessions where new features are presented and discussed.
    \item \textbf{Enhancing Support Tools:}
          We will improve ways to contact the developers (emails, gitlab issues, mailing lists) and provide more detailed information on how to use scimba.
    \item \textbf{Integrating Training with Academic and Industrial Outreach:}
          We propose the following strategy for integrating training activities with academic and industrial outreach efforts, some of which are already in place:
          \begin{itemize}
              \item \textbf{Academic Outreach:}
                    At the local level, we will continue to offer semester projects and internships to students for hands-on experience.
                    At the (inter)national level, we will continue fostering existing relationships with academic institutions, and establish new partnerships to promote scimba training.
              \item \textbf{Industrial Outreach:}
                    We have already partnered with Thales, and are actively promoting the use of scimba in our common projects. We will continue to foster these relationships and establish new partnerships with other industrial partners.
          \end{itemize}
\end{itemize}
