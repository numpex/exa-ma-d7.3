\paragraph{Additional Details:}
\begin{description}
\item[\textbf{Documentation}] % start of item
\emph{Short Description: User manuals, reference guides, and detailed usage instructions.}

\begin{itemize}
  \item The documentation covers the installation, the usage for different user levels (beginner, intermediate, advanced), some explanation of how it works under the hood, and the API.
  \item The documentation is built using sphinx and available on readthedocs. Then, it is available as webpages, epub and PDF.
  \item The documentation will be improved and reorganized in the next months to give a better user experience. Some techniques that can be found in \href{https://www.writethedocs.org}{Write the Docs} will be used.
\end{itemize}

\item[\textbf{Tutorials}]
\emph{Short Description: Hands-on or step-by-step guides designed for newcomers and practitioners.}

\begin{itemize}
\item \textbf{Content:} explanation of how to use samurai to solve pdes using finite volume methods, how to create our own adapted mesh, ...
\item \textbf{Target Audience:} Users of samurai
\item \textbf{Format:} Available as webpages
\end{itemize}

\item[\textbf{Initial Training: Master 1 and 2}]
\emph{Short Description: Introductory courses tailored for academic levels from Bachelor to Doctoral.}

\begin{itemize}
\item \textbf{Academic Levels:} Master 2
\item \textbf{Target Audience:} Students focused on applied mathematics or application-oriented fields
\item \textbf{Frequency:} Offered 1 time per semester
\end{itemize}

\end{description}


\subsubsection{Next Steps for Samurai}
\label{sec:Samurai:next-steps}

\begin{itemize}
        \item \textbf{Better Structure Content:} There are a number of studies explaining how to make documentation engaging for new users. The \href{https://www.writethedocs.org}{writethedocs} site gives some ideas on how to improve the readability of documentation and the topics it should cover. Over the coming months, we will be working on improving the structure and content by following these guidelines.
        \item \textbf{Benchmark Content:} The adoption of software by a community depends on transparency and a clear vision of the performance that can be achieved. We therefore propose to add a list of benchmarks in the very near future, so that you can see what performance you can expect from samurai. A document summarizing the results will be available in the form of a web page.
        \item \textbf{Hands-on Workshops:} We want to make sure that samurai will establish itself over the next few years as a reference software package for dealing with different mesh adaptation methods, thanks to the quality of its mathematical methods, its efficient implementation for discussion between different grid levels, its ease of use, etc. To achieve this, we need to promote samurai through a number of hands-on workshops. We will be working on the materials for these workshops, which will be in the form of notebooks.
\end{itemize}
