\paragraph{Additional Details:}

\begin{description}
\item[\textbf{Documentation}] % start of item
\emph{PDF User guide and documentation are available online}: \newline 
\href{https://ffaucher.gitlab.io/hawen-website/download/hawen_users-guide_documentation.pdf}
{https://ffaucher.gitlab.io/hawen-website/download/hawen\_users-guide\_documentation.pdf} available from website 
       \href{https://ffaucher.gitlab.io/hawen-website/}
            {https://ffaucher.gitlab.io/hawen-website/}

\begin{itemize}
\item \textbf{Content:} 
The documentation gives details regarding installation of the software, its use and benchmark tests.
All of the code features are detailed in the user manual.
\item \textbf{Format:} Available as a PDF document and on the webpages. There is also the Doxygen documentation.
\item \textbf{Development:} Ongoing work to enrich the documentation.
\end{itemize}



\item[\textbf{Tutorials}] Guide for installation and tutorials for using the software are available online: 
      \href{https://ffaucher.gitlab.io/hawen-website/#tutorial}{https://ffaucher.gitlab.io/hawen-website/$\#$tutorial}
\begin{itemize}
\item \textbf{Content:} The guides detail the software installation and dependencies, and give some guidelines for test cases and applications. In addition, a Guix recipe is available to install the 
software.
\item \textbf{Target Audience:} Newcomers and Users.
\item \textbf{Format:} PDF documentation, also available as webpages.
\item \textbf{Development:} Ongoing work to enrich the number of test-cases to cover all of the code features.
\end{itemize}

\end{description}



\subsubsection{Next Steps for Hawen}
\label{sec:Hawen:next-steps}

Below are some informations on the next steps for training with Hawen:

\begin{itemize}
    \item \textbf{New Training Content:} 
    Additional tutorial tests will be prepared so that all features 
    of the software can be tested by newcomers. They will be available
    in the documentation and on the website.
    A recipe with GUIX is existing and need to be updated to facilitate 
    the installation of the software on different architectures.
    Interactive sessions will be used to promote the use of the software with 
    local students and to introduce the code.

    \item \textbf{Incorporating Exascale Techniques and User Feedback:}
    The code performance will be documented and update with future release version.
    User feedbacks will be enforced to highlight the help optimize the necessary 
    features, while exascale algorithm will be incorporated.
    
    \item \textbf{Integrating Training with Academic and Industrial Outreach:}
    \begin{itemize}
      \item \textbf{Academic outreach}: 
             Develop guides adapted to the level students (BSc., Master and post-graduate) 
             to facilitate the usage of the software for all academic levels. 
             Design student projects based on the software and adapted to their levels.
      \item \textbf{Industrial outreach}:
             Present the advanced features and performance to industrial partners,
             and offer guidelines for advanced usage in the context of specific
             case-study.
    \end{itemize}
          
\end{itemize}
