\subsubsection{Next Steps for Hawen}
\label{sec:Hawen:next-steps}

Below are some guiding questions to help outline the next steps for training with Hawen:
\begin{itemize}
    \item What new training content or updates are planned for Hawen in the upcoming milestones? \newline
    Additional tutorial tests will be prepared so that all features 
    of the software can be tested by newcomers. 
    
    
    \item How will the training materials be updated to incorporate the latest exascale techniques and user feedback? \newline
    A recipe with GUIX is existing and need to be updated to facilitate 
    the installation of the software on different architectures.
    
    
    \item Which new delivery formats (e.g., webinars, interactive sessions, hands-on workshops) should be introduced? \newline
    Interactive sessions will be used to promote the use of the software with 
    local students and to introduce the code.
    
    \item What additional documentation or support tools are needed to help users get started or deepen their expertise?
    The code already contained a documentation and tutorials, that will be enriched
    to promote all of the features of the code.
    
    \item How can we better integrate training activities with 
          academic and industrial outreach efforts?
          
\end{itemize}
