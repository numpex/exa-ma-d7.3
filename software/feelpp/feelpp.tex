\paragraph{Additional Details:}

\begin{description}
\item[\textbf{Documentation}] % start of item
\emph{Short Description: User manuals, reference guides, and detailed usage instructions.}

\begin{itemize}
  \item Topics covered are: installation, usage, advanced features, benchmarking, testcases, and API
  \item Format : webpages and notebooks. Jupyter notebooks are provided for some pages
  \item The document is an on-going open-source effort using Asciidoc and Antora and where contributions are welcome
\end{itemize}

\item[\textbf{Tutorials}] % start of item
\emph{Short Description: Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
  \item Steps included are: environment setup, using testcases, using applications and progamming interface
  \item The main target audience : the user of Feel++
  \item The format : webpages and notebooks
  \item The hands-on/step by step guides are an on-going open-source effort using Asciidoc and Antora and where contributions are welcome
\end{itemize}

\item[\textbf{Initial Training::Master 1 and 2}] % start of item
\emph{Short Description: Introductory courses for academic levels from Bachelor to Doctoral.}

\begin{itemize}
  \item Academic levels: Master 1, Master 2, Doctoral
  \item The audience is for applied mathematics or application oriented students
  \item The frequency : 1 to 2 per semester
\end{itemize}

\end{description}


\subsubsection{Next Steps for Feel++}
\label{sec:Feel++:next-steps}

Below are some guiding questions to help outline the next steps for training with Feel++:
\begin{itemize}
    \item New training content include: videos, automated tutorial generation, documentation updates and creation for upcoming releases
    \item \textit{How will the training materials be updated to incorporate the latest exascale techniques and user feedback?} We plan on using the feelpp.benchmarking framework to document systematically the performance of Feel++ and its components, this will help update the performannce tuning documentation.
    \item \textit{Which new delivery formats (e.g., webinars, interactive sessions, hands-on workshops) should be introduced?} webinars, interactive sessions, workshops
    \item \textit{What additional documentation or support tools are needed to help users get started or deepen their expertise?} currently we believe we cover a lot of different aspects in our documentation
    \item \textit{How can we better integrate training activities with academic and industrial outreach efforts?}
\end{itemize}
