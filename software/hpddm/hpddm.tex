\paragraph{Additional Details:}

\begin{description}
\item[\textbf{Documentation}]
\emph{A cheat sheet is available in the GitHub repository, along with a description of the API specific to PETSc on the PETSc website.}

\begin{itemize}
  \item \textbf{Topics Covered:} Usage and performance tuning
  \item \textbf{Format:} PDF and web pages
  \item \textbf{Timeline:} A more detailed introduction to the preconditioners implemented in HPDDM will be made available in the PETSc user-guide at \url{https://petsc.org/release/manual/ksp/#block-jacobi-and-overlapping-additive-schwarz-preconditioners}.
\end{itemize}

\item[\textbf{Tutorials}]
\emph{Short Description: Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
  \item \textbf{Modules Included:} Overlapping and non-overlapping preconditioners setup and theory, tuning parameters
  \item \textbf{Target Audience:} Graduate students and domain scientists
  \item \textbf{Existing Materials:} \url{https://joliv.et/FreeFem-tutorial/}, sections 6, 7, and 8
\end{itemize}

\end{description}

\subsubsection{Next Steps for HPDDM}
\label{sec:HPDDM:next-steps}

To enhance HPDDM training, we've identified key areas to focus on. Some efforts are already in progress, and the following sections outline our strategic goals and additional steps to improve our training programs.


\begin{itemize}
    \item \textbf{New Training Content:}
    \begin{itemize}
        \item \textbf{PETSc User-Guide:} Add a new section detailing the preconditioners implemented in HPDDM.
        \item \textbf{Tutorials:} Develop tutorials for FreeFEM days, PETSc annual meetings, and SIAM conferences.
    \end{itemize}

    \item \textbf{Incorporating Exascale Techniques and User Feedback:}
    \begin{itemize}
        \item \textbf{GPU Utilization:} Update training materials to include links and sections on how to use GPUs effectively.
        \item \textbf{User Feedback:} Establish a structured feedback loop to incorporate user experiences and suggestions into future updates.
    \end{itemize}

    \item \textbf{Expanding Delivery Formats:}
    \begin{itemize}
        \item \textbf{Hands-On Workshops:} Organize workshops that focus on practical applications of HPDDM.
        \item \textbf{Interactive Sessions:} Conduct interactive sessions where participants can engage in hands-on activities and receive real-time feedback.
    \end{itemize}

    \item \textbf{Enhancing Support Tools:}
    \begin{itemize}
        \item \textbf{Interactive Documentation:} Enhance the documentation with interactive elements such as code snippets and live examples.
    \end{itemize}
\end{itemize}
