\emph{There is a cheat sheet available in the GitHub repository, and a description of the API specific to PETSc on the PETSc website.}

\begin{itemize}
  \item Which topics are covered (installation, usage, performance tuning, advanced features)? Usage and performance tuning.
  \item What will be the final format (PDF, Wiki, Jupyter notebooks, web pages)? PDF and web pages
  \item What is the expected timeline or milestone for completing the documentation? A more detailed introduction to the preconditioners implemented in HPDDM will be made available in PETSc user-guide at \url{https://petsc.org/release/manual/ksp/#block-jacobi-and-overlapping-additive-schwarz-preconditioners}.
\end{itemize}

\item[\textbf{Tutorials}] % start of item
\emph{Short Description: Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
  \item Which modules or steps are included (environment setup, HPC job submission, scaling tests, performance benchmarks)? Overlapping and non-overlapping preconditioners setup and theory, tuning parameters 
  \item Who is the main target audience (undergraduates, HPC engineers, domain scientists)? Graduate students and domain scientists
  \item Is there a link to any draft or existing tutorial materials? \url{https://joliv.et/FreeFem-tutorial/}, sections 6, 7, and 8
\end{itemize}

\end{description}


\subsubsection{Next Steps for HPDDM}
\label{sec:HPDDM:next-steps}

Below are some guiding questions to help outline the next steps for training with HPDDM:
\begin{itemize}
    \item What new training content or updates are planned for HPDDM in the upcoming milestones? New section in PETSc user-guide, tutorials during FreeFEM days, PETSc annual meetings, and SIAM conferences.
    \item How will the training materials be updated to incorporate the latest exascale techniques and user feedback? Links to sections of manuals highlighting how to use GPUs
    \item Which new delivery formats (e.g., webinars, interactive sessions, hands-on workshops) should be introduced? Hands-on workshops, PDF, and web pages
\end{itemize}
