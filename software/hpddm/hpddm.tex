\paragraph{Additional Details:}
\begin{description}
\item[\textbf{Documentation}] % start of item
\emph{Short Description: User manuals, reference guides, and detailed usage instructions.}

\begin{itemize}
  \item Which topics are covered (installation, usage, performance tuning, advanced features)?
  \item What will be the final format (PDF, Wiki, Jupyter notebooks, web pages)?
  \item What is the expected timeline or milestone for completing the documentation?
\end{itemize}

\item[\textbf{Tutorials}] % start of item
\emph{Short Description: Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
  \item Which modules or steps are included (environment setup, HPC job submission, scaling tests, performance benchmarks)?
  \item Who is the main target audience (undergraduates, HPC engineers, domain scientists)?
  \item Is there a link to any draft or existing tutorial materials?
\end{itemize}

\item[\textbf{SIAM}] % start of item
\emph{Short Description: Trainings or sessions associated with SIAM conferences or workshops.}

\begin{itemize}
  \item Does the training coincide with SIAM conferences (e.g., CSE, PP) or related workshops?
  \item Is there a minisymposium or tutorial under a SIAM umbrella?
  \item Which HPC or exascale topics are highlighted in this context?
\end{itemize}

\item[\textbf{CEA/INRIA/EDF}] % start of item
\emph{Short Description: Joint trainings by CEA, INRIA, EDF, and possibly academic partners.}

\begin{itemize}
  \item Which of these organizations (CEA, INRIA, EDF) are co-organizing the training?
  \item Is the training aimed at novices or advanced HPC developers, or a mix?
  \item What academic or industrial collaborations enhance the training content?
\end{itemize}

\end{description}
