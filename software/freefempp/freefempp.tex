\item[\textbf{Documentation}] % start of item
\emph{Online and PDF documentation with online search and 600+ examples}

\begin{itemize}
  \item Which topics are covered (installation, usage, performance tuning, advanced features)? Installation, usage, advanced features
  \item What will be the final format (PDF, Wiki, Jupyter notebooks, web pages)? PDF, web pages, runnable Markdown-commented examples
  \item What is the expected timeline or milestone for completing the documentation? Jointly with the upcoming packaging efforts, the deployement steps with package managers (including on supercomputers) with be added to the documentation
\end{itemize}

\item[\textbf{Tutorials}] % start of item
\emph{Short Description: Hands-on or step-by-step guides for newcomers and practitioners.}

\begin{itemize}
\item Step-by-step guide for newcomers and practitioners\\\url{https://joliv.et/FreeFem-tutorial}\\Covers installation, basics, advanced parallel usage with PETSc\\
\item Video series introducting FreeFEM\\\url{https://www.youtube.com/playlist?list=PL6fjYEpJFi7Wu9ZFlak7r0QgrF0aNi8H1}\\External contribution by M. Barzegari (TU/e Eindhoven)\\Video tutorials and demos covering basics, adaptive mesh generation, vizualization, I/O and parallel capabilities\\
\item FreeFEM days\\\url{https://freefem.org/ffdays.html}\\Two-day hybrid in-person + remote developer-user meetup held mid-December each year with scientific presentations as well as beginner- and expert-level hands-on sessions. Expert tutorials highlight advanced parallel capabilities with PETSc\\
\item FreeFEM youtube channel\\\url{https://www.youtube.com/@freefem9826}\\Presentations and hands-on sessions for newcomers and practitioners ; compiles presentations and tutorials from the FreeFEM days\\
\end{itemize}

\end{description}
